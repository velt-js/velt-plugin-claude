# Velt Plugin for Claude Code

Add real-time collaboration (comments, presence, cursors, CRDT editing, notifications) to React and Next.js apps using AI-assisted setup.

## Installation

```bash
claude --plugin-dir /path/to/velt-plugin-claude
```

Or via marketplace once published.

## What You Get

- **8 slash commands**: `/install-velt`, `/add-comments`, `/add-crdt`, `/add-notifications`, `/add-presence`, `/add-cursors`, `/screenshot`, `/velt-help`
- **4 agent-skills**: velt-setup, velt-comments, velt-crdt, velt-notifications (118 implementation rules)
- **Velt Expert agent**: specialized AI persona for Velt architecture guidance
- **Embedded best practices**: Combined rules guide for quick reference
- **MCP servers**: velt-installer (guided setup) + velt-docs (documentation search)

## Quick Start

1. Start Claude Code with the plugin
2. Type `/install-velt`
3. Follow the guided setup (API key, features, approval)
